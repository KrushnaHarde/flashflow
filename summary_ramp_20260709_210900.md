- **Likely Cause**: Redis Command Completion Delay
- **Evidence**: Redis lettuce max response latency hit 25.8ms.
- **Recommendation**: Batch Redis operations using MGET/MSET pipelines or bundle commands in a single transactional Lua script.

### Stage: 10_rps (PASS)

### Stage: 100_rps (FAIL)
- **Likely Cause**: Database Connection Pool Saturation
- **Evidence**: Hikari active connections reached 22.7/50. Active threads waiting: 140.
- **Recommendation**: Increase spring.datasource.hikari.maximum-pool-size in application.properties or scale database resource instances.

### Stage: 500_rps (FAIL)
- **Likely Cause**: Tomcat Connector Backlog/OS Port Exhaustion
- **Evidence**: Error rate reached 74.6% due to connection refusals.
- **Recommendation**: Increase server.tomcat.threads.max or apply OS registry overrides to increase TCP max ports.

### Stage: 1k_rps (INCONCLUSIVE)

- **Evidence**: k6 dropped 3,233,937 load-testing iterations. The client machine ran out of sockets/CPU resources to generate the target load.
- **Recommendation**: Move the k6 test runner execution to a separate machine on the network, or configure distributed load generation nodes.

### Stage: 10k_rps (INVALID)

## Actionable Optimization Recommendations

### Database Connection Pool
Increase the HikariCP pool size (e.g. spring.datasource.hikari.maximum-pool-size=50) and evaluate slow queries. Ensure the tables have proper indexes (particularly reservations and outbox_events). Enable Hibernate JDBC batching properties.

### Redis Cache Layer
Optimize Lettuce Redis connection sharing. Use Redis pipeline operations or wrap multiple commands into single atomized Lua scripts inside RateLimiterService and RedisInventoryService to reduce roundtrip execution cycles.

### Load Generation & OS Backlog
When local loopback connection limits are hit (resulting in refused connections at 5k+ RPS), scale load testing horizontally by running distributed k6 nodes or optimize local Windows registry TCP backlog configurations (MaxUserPort and TcpTimedWaitDelay).
